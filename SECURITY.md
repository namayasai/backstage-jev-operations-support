# Security

Do not post credentials or private operational data in public issues. Use GitHub's private vulnerability reporting for this repository when available. If it is unavailable, open a minimal issue asking for a private contact without including exploit details or sensitive data.

The plugin's model outputs are advisory. They are not authorization checks, deployment gates, or security certifications. Backstage authentication and permission policy remain the authority for access. See the README and installation guide for data flow and deployment limits.
